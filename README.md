# CellScope 荧光细胞计数

## 直接使用网页

打开 **https://weigenwu.github.io/cellcount/**，选择整个实验文件夹即可使用。

- 图片在浏览器本地读取和分析，不会上传到 GitHub 或其他服务器。
- 支持 Leica LAS X 的 `Overlay*_ch00/ch01/ch02` 目录，也可以修改三通道后缀。
- 浏览器一次只处理一个视野，避免同时载入整批大 TIFF。
- 三条通道默认显示为 DAPI、NK、肿瘤，也可在页面中改成任意细胞或染色名称；名称会同步到结果表、CSV 和项目文件。
- 三条通道分别保存计数方式和对应参数，互不覆盖。
- 每个类别都支持“当前组随机抽一张预跑”，确认阈值后再一键批量处理全部视野。
- 可在“原图＋真实轮廓”和 ImageJ 风格“二值核对图”之间切换；编号位于实际分割对象中央。
- 可用“添加细胞”直接补计漏识别对象，用“删除细胞”直接点掉误识别对象；也可先选择标记后按 Delete 删除。计数 CSV、项目 JSON、错误报告及三通道全分辨率标注 PNG 可一次导出。
- 放大后可点“拖拽图片”左键平移，也可随时按住空格再左键拖动或使用鼠标中键；滚轮会以光标位置为中心缩放，“适应”和“居中”可快速恢复视野。
- 主图左右两侧可切换当前小文件夹的上一张/下一张，顶部显示文件夹内位置；切换时保持 DAPI、NK、肿瘤或 CIC 当前通道及其轮廓，也可使用键盘 `←` / `→` 连续逐张复核。
- 点击“双视野比较”可将任意两张视野并排复核；左右通道可独立选择，合并图会同时显示 D/N/T 三类真实轮廓，默认按图像坐标同步缩放和拖拽，也可关闭同步后单独查看。
- 参数、批处理结果和人工修正会自动保存到浏览器本地数据库；重新选择同名原始文件夹即可恢复。人工添加、删除和 CIC 判定支持页面按钮或 `Ctrl+Z` / `Ctrl+Y` 撤销与重做。
- 导入包含多个子文件夹的大目录后，可勾选任意一个或多个子文件夹批量处理；项目 JSON 会保存当前勾选范围。
- 完整导出会在 `按原目录排列` 下重建原子文件夹层级，每个已处理文件夹分别包含计数结果、错误报告和三通道标注图，根目录另有全部文件夹汇总。
- CIC 模块会额外筛查 NK–肿瘤异质候选和肿瘤–肿瘤同质候选；自动候选默认不计入最终结果，必须人工确认为“异质”或“同质”。
- CIC 导出包含逐事件原始数据、组汇总、每视野均值±标准差 PNG/SVG 图和全分辨率 CIC 标注图；原有计数汇总、细胞逐对象原始数据、项目 JSON 和三通道标注图仍会同时导出。
- TIFF 解码库已内置在网页仓库中，运行和分析过程不依赖第三方 CDN；原始图片始终只在当前浏览器标签页内解码。

> 浏览器版采用 JavaScript 近似分水岭。正式分析前必须使用人工计数视野校准，重要分析建议与下方 Python 本地版交叉验证。

## CIC 候选筛查

推荐顺序：

1. 依次完成 DAPI、NK、肿瘤计数和必要的人工增删。
2. 三类计数操作位于右侧面板上方；CIC 面板固定在其后并默认折叠，完成进度达到 3/3 后才启用对应的 CIC 当前图或批量按钮。
3. 点击顶部“CIC 复核”，使用“跳到下一个待复核候选”逐个检查。
4. 只有点击“确认异质”或“确认同质”的事件才进入最终 CIC 统计；“排除”和仍待复核的事件保留在原始数据中，但不进入确认数。

当前算法依据完整包围、内外红色信号差异、内部/外部细胞核及细胞类型组合生成二维候选。单层宽场图无法可靠区分真正内吞与上下叠加，因此软件明确将自动结果标记为候选而非确诊。判定设计参考：

- [AIM-CICs 自动识别研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9701057/)
- [肿瘤细胞与 NK 细胞异质 CIC 成像研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9464952/)
- [多重成像中的 CIC 六项结构判据](https://pmc.ncbi.nlm.nih.gov/articles/PMC12338647/)
- [Cell-in-cell 结构分类综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC8534218/)

### 标注 PPT 增强判定

用户标注的 NK–肿瘤 CIC 代表性图片用于优化异质 CIC 的二维候选规则。推荐策略会：

- 排除 NK 与肿瘤结果共用同一 DAPI 核坐标的假双阳性。
- 联合检查红色信号包围比例、四象限覆盖、对侧支持、最大连续缺口，以及近层/远层径向一致性，而不是只按总重叠面积判定。
- 将接近完整包围的候选标为 A 级，将标注中常见的多方向部分包围标为 B 级；单侧贴靠不会因局部红绿重叠进入候选。
- 排除明显大于同视野 NK 核中位尺寸的自动分割团块；人工添加的细胞不受该门控限制。
- 在 `CIC逐事件原始数据.csv` 中导出证据等级、判定规则、各方向形态指标、核间距离和面积比例，便于后续用人工确认结果继续校准。

标注 PPT 主要提供异质 CIC 示例，因此同质 CIC 仍使用原有更保守的完整包围规则。A/B 级均为待复核候选，不会自动计入最终 CIC 数量。

CellScope 是针对三通道荧光显微图像的本地批量计数工具。默认识别 Leica LAS X 导出的：

- `*_ch00`：DAPI（蓝）
- `*_ch01`：NK（绿）
- `*_ch02`：肿瘤（红）
- 无通道后缀的同名文件：合并图

## Python 本地版

1. 双击 `启动细胞计数网页.bat`。首次运行会建立 `.venv` 并安装依赖，之后无需联网。
2. 浏览器打开后选择实验文件夹。
3. 分别为 DAPI、NK、肿瘤选择代表性视野并调整参数，再按类别批量分析。
4. 检查标记，必要时添加或删除当前类别的细胞。
5. 导出 CSV、项目 JSON、错误报告和可选的全分辨率标注图。

服务只绑定 `127.0.0.1:8765`，图片不会上传。关闭启动窗口即可停止。

## 参数说明

- 新项目第一通道默认使用手动阈值 `15–255`、面积 `400–20000 px²`、圆度 `0.30–1.00`、平滑半径 `1`、分水岭抑制 `12`。
- 第二、第三通道默认采用核引导阳性判定：背景校正信号阈值分别为 `10`、`15`，阳性像素比例 `0.10`，核周半径 `6 px`。
- 最小面积 `400 px²` 在当前 Leica 元数据 `0.218 µm/px` 下约为 `19.0 µm²`。
- 自适应分水岭会比较局部峰间距与峰谷深度，抑制同一细胞核内的浅峰；抑制值越大，切割越少。
- 三条通道拥有各自独立的分析模式和参数；修改显示名称不会改变蓝、绿、红通道与文件后缀的对应关系。
- 三类参数独立保存，推荐依次完成“随机预跑、校准、批量计数”。
- 第一通道默认做自适应细胞核分割；第二、第三通道默认按每个细胞核及核周区域的背景校正信号判定阳性，避免把连续胞质或荧光斑点误当成多个细胞。
- 第二、第三通道可切换回“独立颗粒切割”，用于确实需要直接统计颗粒的其他染色。
- 点击查看器上方的蓝、绿、红单通道会同步切换当前计数对象；分析按钮始终显示即将处理的通道名称。
- 第二、第三通道会读取第一通道的人工修正作为核锚点，但重新分析第二或第三通道不会修改或清除第一通道结果。

正式实验统计前必须使用人工计数样本校准阈值。
