# CellScope 荧光细胞计数

打开 **https://weigenwu.github.io/cellcount/**，选择整个实验文件夹即可在浏览器中批量计数。图片只在本机读取和分析，不会上传。

## 功能

- 默认计数 DAPI、NK 和肿瘤三类，也可修改三条通道的显示名称。
- 递归读取大文件夹下的子文件夹，可勾选任意实验组后按类别批处理。
- 逐视野读取 Leica XML 中的 Blue、Green、Red LUT 顺序，不再假定 `ch00/ch01/ch02` 固定。只有一条通道的 XML 也会保留该视野并明确标记缺失通道。
- 三类参数分别保存；可先随机预跑一张，确认后再批量分析。
- DAPI 使用阈值、形态学清理和自适应分水岭分核。
- NK/肿瘤默认按 DAPI 核引导判阳性：核周距离按 `µm/px` 换算，局部中位数＋MAD 校正背景，排除邻近核污染并过滤过小连通信号块。
- 红/绿轮廓显示真实阳性信号块，编号继承对应 DAPI 核，方便逐核核对。
- 可添加、删除标记，支持撤销/重做、缩放拖拽、上一张/下一张和双视野并排比较。
- 可单独下载纯白底多工作表 Excel；完整导出同时包含同一份 XLSX、逐对象原始数据、项目 JSON、错误报告和三通道全分辨率标注 PNG。标注图文件名使用每个视野的实际通道映射。
- DAPI 核被重跑或人工改变时，依赖旧核坐标的 NK/肿瘤结果会明确失效并要求重跑，避免编号与轮廓静默错配。
- 直接写入文件夹时，每次导出会新建带时间戳的独立结果目录，避免旧版本文件残留混入本次结果。
- 浏览器不允许直接写入文件夹时，自动改为下载保持相同目录结构的 ZIP。

## 参数

- DAPI 默认：手动阈值 `15–255`、面积 `400–20000 px²`、圆度 `0.30–1.00`、平滑 `1`、分水岭抑制 `12`。
- NK/肿瘤核引导默认：最小信号差 `10/15`、阳性像素比例 `0.05`、核周 `2 µm`、MAD 倍数 `3`、最小连通块 `0.5 µm²`。
- 旧项目只保存 `ring_radius_px` 时会自动按当前视野像素尺寸转换，不会丢失旧参数。
- 图像右下角检测到白色比例尺时会在颗粒分割和真实信号掩膜中屏蔽。

正式统计前请用人工计数视野校准各实验组参数。
