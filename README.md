# CellScope 本地细胞计数

CellScope 是针对三通道荧光显微图像的本地批量计数工具。默认识别 Leica LAS X 导出的：

- `*_ch00`：DAPI（蓝）
- `*_ch01`：NK（绿）
- `*_ch02`：肿瘤（红）
- 无通道后缀的同名文件：合并图

## 使用

1. 双击 `启动细胞计数网页.bat`。首次运行会建立 `.venv` 并安装依赖，之后无需联网。
2. 浏览器打开后选择实验文件夹。
3. 先在代表性视野中调整每个实验组的参数，再分析当前视野或批量分析。
4. 检查标记，必要时添加、删除或修改类别。
5. 导出 CSV、项目 JSON、错误报告和可选的全分辨率标注图。

服务只绑定 `127.0.0.1:8765`，图片不会上传。关闭启动窗口即可停止。

## 参数说明

- DAPI 阈值默认使用旧 ImageJ 宏中的 `20–129`。
- 最小面积默认 `400 px²`；当前 Leica 元数据为 `0.218 µm/px` 时约为 `19.0 µm²`。
- 分水岭用于拆分相互接触的细胞核。
- 肿瘤/NK 分类使用核周区域中相对局部背景达到强度阈值的像素比例。
- 红绿同时阳性的细胞标为“待复核”，不会自动重复计数。

正式实验统计前必须使用人工计数样本校准阈值。
