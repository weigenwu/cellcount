# CellScope 荧光细胞计数

## 直接使用网页

打开 **https://weigenwu.github.io/cellcount/**，选择整个实验文件夹即可使用。

- 图片在浏览器本地读取和分析，不会上传到 GitHub 或其他服务器。
- 支持 Leica LAS X 的 `Overlay*_ch00/ch01/ch02` 目录，也可以修改三通道后缀。
- 浏览器一次只处理一个视野，避免同时载入整批大 TIFF。
- 三条通道默认显示为 DAPI、NK、肿瘤，也可在页面中改成任意细胞或染色名称；名称会同步到结果表、CSV 和项目文件。
- 三条通道分别保存计数方式和对应参数，互不覆盖。
- 每个类别都支持“当前组随机抽一张预跑”，确认阈值后再一键批量处理全部视野。
- 可在“原图＋真实轮廓”和 ImageJ 风格“二值核对图”之间切换；编号位于实际分割对象中央。
- 可人工增删当前类别标记，并导出三类独立计数 CSV、项目 JSON 和当前标注图。

> 浏览器版采用 JavaScript 近似分水岭。正式分析前必须使用人工计数视野校准，重要分析建议与下方 Python 本地版交叉验证。

CellScope 是针对三通道荧光显微图像的本地批量计数工具。默认识别 Leica LAS X 导出的：

- `*_ch00`：DAPI（蓝）
- `*_ch01`：NK（绿）
- `*_ch02`：肿瘤（红）
- 无通道后缀的同名文件：合并图

## Python 本地版

1. 双击 `启动细胞计数网页.bat`。首次运行会建立 `.venv` 并安装依赖，之后无需联网。
2. 浏览器打开后选择实验文件夹。
3. 分别为 DAPI、NK、肿瘤选择代表性视野并调整参数，再按类别批量分析。
4. 检查标记，必要时添加或删除当前类别的细胞。
5. 导出 CSV、项目 JSON、错误报告和可选的全分辨率标注图。

服务只绑定 `127.0.0.1:8765`，图片不会上传。关闭启动窗口即可停止。

## 参数说明

- 新项目第一通道默认使用手动阈值 `15–255`、面积 `400–20000 px²`、圆度 `0.30–1.00`、平滑半径 `1`、分水岭抑制 `12`。
- 第二、第三通道默认采用核引导阳性判定：背景校正信号阈值分别为 `10`、`15`，阳性像素比例 `0.10`，核周半径 `6 px`。
- 最小面积 `400 px²` 在当前 Leica 元数据 `0.218 µm/px` 下约为 `19.0 µm²`。
- 自适应分水岭会比较局部峰间距与峰谷深度，抑制同一细胞核内的浅峰；抑制值越大，切割越少。
- 三条通道拥有各自独立的分析模式和参数；修改显示名称不会改变蓝、绿、红通道与文件后缀的对应关系。
- 三类参数独立保存，推荐依次完成“随机预跑、校准、批量计数”。
- 第一通道默认做自适应细胞核分割；第二、第三通道默认按每个细胞核及核周区域的背景校正信号判定阳性，避免把连续胞质或荧光斑点误当成多个细胞。
- 第二、第三通道可切换回“独立颗粒切割”，用于确实需要直接统计颗粒的其他染色。

正式实验统计前必须使用人工计数样本校准阈值。
